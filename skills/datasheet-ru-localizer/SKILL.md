# Локализатор даташитов (RU, стиль Акметрон)

Превращает даташит вендора в полностью переведённый русский PDF в фирменном
оформлении Акметрон. Содержимое отделено от вёрстки: дизайн (CSS + рендерер +
шрифты + логотип) фиксирован и лежит в `assets/`; под каждый новый даташит ты
генерируешь **только** слой контента — объект `window.DATASHEET` — и рендеришь PDF.

## Что неизменно (НЕ редактировать)

`assets/datasheet.css`, `assets/renderer.js`, `assets/photoslot.js`,
`assets/fonts/`, `assets/puzzle-pattern.svg`, `assets/logo-mark.png`,
`assets/render_pdf.py`. Это и есть «дизайн Акметрон». Трогаешь только контент.

## Обязательное условие: фотография прибора

**Без реальной фотографии прибора даташит не формируется.** Обложка строится
вокруг фото изделия — плейсхолдеров «перетащите фото» больше нет.

- Если пользователь не приложил фото прибора — **не запускай рендер**. Сначала
  попроси прислать фотографию (PNG/JPG/WebP, желательно на белом/прозрачном фоне).
- Фото передаётся третьим аргументом в `render_pdf.py` и встраивается в PDF.
- Логотип (`assets/logo-mark.png`) — сейчас плейсхолдер; если пользователь даёт
  настоящий логотип, замени файл (имя оставь прежним). Логотип встраивается как
  data-URI, поэтому не «теряется» при печати.

## Рабочий процесс

### 0. Проверить наличие фото прибора

Нет фото → остановись и запроси его у пользователя. Не рендери без фотографии.


### 1. Прочитать исходный даташит

- **Текстовый PDF** (текст выделяется): извлеки текст и **структуру таблиц**
  через `pdfplumber` (`page.extract_tables()` + `extract_text()`). Если PDF уже
  виден в контексте как текст/изображение — используй его напрямую, но всё равно
  сверяйся со структурой таблиц, чтобы ничего не потерять.
- **Скан / изображение**: растеризуй страницы и распознай через `tesseract`
  (язык `eng` — даташиты обычно англоязычные), затем переводи распознанное.
  ```bash
  # пример OCR одной страницы
  tesseract page-3.png stdout -l eng
  ```
- Зафиксируй: обложку, перечень разделов, для каждого раздела — подразделы,
  группы параметров, строки «параметр → значение», условия, примечания, списки,
  сноски, колонтитулы, копирайт и код документа.

### 2. Перевести ПОЛНОСТЬЮ на русский

Прочитай `references/glossary.md` и следуй ему. Ключевое:
- Переводится **каждая** строка/таблица/примечание. Сокращать и обобщать нельзя.
- Порядок разделов и таблиц — 1:1 с оригиналом.
- Десятичная запятая (`0,43`), единицы переводятся (`GHz`→`ГГц`…), диапазоны через
  тире, квалификаторы `typical/nominal/warranted` → поле `q` (`t/n/w`).
- Номера моделей, имена портов/регистров, обозначения стандартов — как в оригинале.
- Брендинг вендора → Акметрон, но `Производитель: <Вендор>` и оригинальный
  копирайт сохраняются (это локализация, не присвоение авторства).

### 3. Собрать слой контента

Скопируй `assets/content.template.js` в рабочий файл (например `content.js`) и
заполни объект `window.DATASHEET`. Типы блоков и строк документированы в шапке
шаблона и в `assets/renderer.js`. Памятка:

```
{ h2: '...' }                    синяя шапка подраздела
{ note: { label, text } }        примечание (проза)
{ list: { label, items:[...] } } маркированный список
{ group: '...', rows:[...] }     группа параметров
{ rows:[...] }                   параметры без группы
{ matrix: { title?, head:[...], widths?:[...], rows:[[...],...] } }
                                 многоколоночная таблица (заказ/опции/прошивки)
строки: { l, v, q } | { sub:'условие' }
квалификатор q: 't'=тип. 'n'=ном. 'w'=гарант. 'm'=изм. 'nt'=н. трасс.
```

Для значений вида «предел, тип. X» пиши оба числа в `v` (например
`v:"< −127 дБн (1 Гц) · тип. −132 дБн (1 Гц)"`); поле `q` — для одиночного
квалификатора при одном значении.

Правила соответствия страниц:
- Первая страница оригинала-обложка → `type:"cover"`. `highlights` — 3 ключевых
  показателя из шапки (значения держи короткими, в одну строку). Фото прибора
  подставляется автоматически из аргумента рендера — `hero` оставляй `null`.
- Каждый РАЗДЕЛ характеристик → один объект `type:"spec"` с `title`, в который
  складываешь **все** блоки раздела. **Не дроби раздел на несколько объектов
  вручную** — рендерер сам разложит длинный раздел по листам A4, повторяя шапку
  раздела и шапку таблицы с пометкой «(продолж.)». Поле `continued` не нужно.
- Сохраняй ВСЕ строки. Лучше лишняя страница, чем потерянная таблица.

### 4. Отрендерить PDF

```bash
cd <путь-к-навыку>/assets
python render_pdf.py /путь/к/content.js /mnt/user-data/outputs/<имя>_ru.pdf /путь/к/фото-прибора.png
```
Третий аргумент — **обязательная** фотография прибора. Скрипт собирает HTML
(фиксированный CSS + рендерер + твой контент), встраивает фото и логотип как
data-URI, грузит в Chromium, ждёт загрузки шрифтов и изображений и печатает A4
PDF с фоновой графикой. Длинные разделы он сам разбивает по листам; печатает
итоговое число листов.

### 5. Проверить и отдать

- Открой выходной PDF (растеризуй пару страниц и просмотри), убедись:
  таблицы на месте, значения и единицы верны, ничего не обрезано, колонтитулы и
  нумерация корректны.
- Сверь число параметров/строк с оригиналом — это главный критерий полноты.
- Отдай файл пользователю через `present_files`.

## Ассеты, которые предоставляет пользователь

- **Фото прибора** — ОБЯЗАТЕЛЬНО. Передаётся третьим аргументом в `render_pdf.py`.
  Без него даташит не формируется (см. «Обязательное условие» выше).
- **Логотип Акметрон**: `assets/logo-mark.png` — сейчас плейсхолдер. Если
  пользователь даёт настоящий логотип, замени файл (имя оставь прежним).

## Частые ошибки

- Сокращение или объединение строк ради компактности — **запрещено**. Полнота важнее.
- Точка вместо запятой в числах; не переведённые единицы; перевод имён портов/моделей.
- Потеря курсивных строк-условий (`sub`) — они несут диапазоны измерений.
- Редактирование `datasheet.css`/`renderer.js` — дизайн менять не нужно, только контент.
